# ♟ 체스 교실 (Chess Learning App)

체스를 처음 배우는 사람을 위한 한국어 학습용 체스 웹앱입니다.
AI와 대결하며 기물의 이동 규칙·전략을 익히거나, 두 명이 한 화면에서 대국할 수 있습니다.
아이폰·아이패드·PC 화면에 맞게 자동 조정되며, 아이폰 홈 화면에 설치한 뒤 오프라인에서도 다시 실행할 수 있습니다.

**🔗 바로 사용하기:** https://kimgun1981.github.io/chess-learning-app/

## 주요 기능

### 🎓 기초 학습
- **20단계 실습** — 기물 이동부터 잡기·체크 회피·캐슬링·프로모션·체크메이트까지 단계별 연습
- 정답이 여러 개인 문제를 지원하고, 오답일 때는 왜 틀렸는지 바로 안내
- 완료한 문제 다시 풀기, 미완료 문제만 복습, 전체 학습 기록 초기화
- 학습 진행도와 완료 단계 수를 현재 브라우저에 자동 저장

### 🤖 1인용 (AI 연습)
- **3단계 난이도** — 초급(무작위) · 중급(기물 잡기·체크·중앙 장악) · 심화(미니맥스 3수 앞 탐색)
- **💡 힌트** — 제한된 계산 시간 안에서 찾은 추천 후보수와 이유를 보여줍니다
- **🤖 AI 수 설명** — AI의 잡기·체크·캐슬링·기물 전개를 한국어로 안내합니다
- **내 수 피드백** — 사용자가 둔 수의 학습 포인트를 즉시 설명합니다
- **기물 설명** — 기물을 클릭하면 이동 규칙이 표시됩니다
- **단계별 팁** — 오프닝·미들게임·엔드게임 상황에 맞는 조언

### 👥 2인용
- **체스 클럭** — 무제한 / 1분 / 3분 / 5분 / 10분 / 30분, 밀리초 단위 실제 경과 시간을 계산해 백그라운드에 다녀와도 정확히 반영
- **잡은 기물 · 점수판** — 양쪽 플레이어의 기물 우위를 실시간 표시
- **마주 보는 배치** — 흑 정보 카드를 180° 회전해 맞은편 플레이어가 읽기 편함
- **대면 대국 편의** — 착수·체크·시간 경고 소리, 진동, 화면 꺼짐 방지 지원(기기와 브라우저가 지원하는 경우)

### 공통
- 체크 / 체크메이트 / 스테일메이트 / 3회 반복 / 50수 규칙 판정
- 캐슬링 · 앙파상 · 폰 프로모션 등 특수 규칙 지원
- 한 수 무르기 · 기보 표시 · 반응형 레이아웃
- 진행 중인 게임 자동 저장 · 이어하기 · 새 저장 게임으로 교체 전 확인
- 표준 PGN 기보 복사·파일 저장
- 게임 승패와 학습 완료 통계
- 홈 화면 설치(PWA) 및 한 번 연 뒤 오프라인 실행
- 아이폰 노치·홈 표시 영역과 가로/세로 화면 대응

## 기술 스택

- **React 19** + **Vite** — UI 및 빌드
- **chess.js** — 규칙 검증 및 국면 관리
- **Tailwind CSS v4** — 스타일링

## 로컬 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드
npm run lint     # 린트 검사
npm test         # 자동 테스트
npm run deploy   # 빌드 후 GitHub Pages 배포
```

`main` 브랜치에 코드를 올리거나 Pull Request를 만들면 GitHub Actions가 `npm test`, `npm run lint`, `npm run build`를 자동 실행해 오류를 확인합니다.

## 아이폰 홈 화면에 설치

1. 아이폰의 **Safari**에서 위 사용 주소를 엽니다.
2. 화면 아래의 **공유** 버튼을 누릅니다.
3. 목록에서 **홈 화면에 추가**를 누릅니다.
4. 오른쪽 위의 **추가**를 누릅니다.

처음 한 번은 인터넷에 연결된 상태로 앱을 열어야 합니다. 준비가 끝난 뒤에는 홈 화면 아이콘으로 오프라인에서도 다시 실행할 수 있습니다.

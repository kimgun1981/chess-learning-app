# 체스 교실 — 기능 설명서

## 개요

**체스 교실**은 React 기반의 웹 체스 학습 앱입니다. 10단계 기초 학습, 1인용 AI 대전, 2인용 대면 대결을 지원하며 아이폰·아이패드·PC에서 사용할 수 있습니다.

- 배포 URL: https://kimgun1981.github.io/chess-learning-app/
- GitHub: https://github.com/kimgun1981/chess-learning-app

---

## 화면 구성

### 1. 메인 메뉴 (ModeSelect)
- 앱 진입 시 가장 먼저 표시
- **기초 학습** / **1인용 (AI 연습)** / **2인용** 모드 선택
- 저장된 대국이 있으면 **지난 게임 이어하기** 표시

### 2. 기초 학습 (LessonSelect / LessonPractice)
- 기물 이동, 기물 잡기, 체크 회피, 캐슬링, 1수 체크메이트 등 10단계
- 기물 선택 시 이동 가능한 칸 표시
- 잘못된 후보수와 정답에 대한 즉시 피드백
- 단계별 완료 상태 자동 저장

### 3. 난이도 선택 (DifficultySelect) — 1인용 전용
- 초급 🌱 / 중급 ⚡ / 심화 🔥 3단계

### 4. 시간 선택 (TimeSelect) — 2인용 전용
- 무제한 / 1분 / 3분 / 5분 / 10분 / 30분

### 5. 게임 화면
- 모드에 따라 AI 모드 또는 2인용 모드 UI 표시

## 핵심 기능

### 체스판
- 8×8 그리드, 유니코드 기물 렌더링
- **흰 말**: ♙♘♗♖♕♔ (hollow, text-white + 다크 아웃라인)
- **검정 말**: ♟♞♝♜♛♚ (solid, text-gray-900 + 화이트 글로우)
- 클릭한 기물의 합법적 이동 칸 하이라이트 (파란 점)
- 체크 상태 킹 칸 빨간 하이라이트
- 힌트 칸 노란 하이라이트
- `grid-rows-8` + `h-full` 로 말 유무와 무관하게 칸 크기 고정

### AI 엔진
| 난이도 | 알고리즘 |
|--------|---------|
| 초급 | 완전 랜덤 |
| 중급 | 그리디 (체크메이트 > 체크 > 기물 잡기 > 중앙 점령 우선) |
| 심화 | 미니맥스 depth=3 + 알파베타 가지치기 |

### 타이머 (2인용)
- 선택한 시간을 각 플레이어에게 배분
- 자기 차례일 때만 카운트다운
- `Date.now()` 기반의 실제 경과 시간을 사용해 아이폰·아이패드의 백그라운드 제한 후에도 정확한 시간 반영
- 30초 이하 + 자기 차례 → 빨간 색 + pulse 애니메이션
- 시간 초과 시 상대방 승리 선언

### 힌트 (1인용)
- 기물 점수, 중앙 활용, 폰 전진과 상대의 다음 대응을 함께 계산
- 출발 칸·도착 칸을 노란색으로 표시하고 추천 이유 안내

### 무르기 (Undo)
- 1인용: 본인 수 + AI 수 한 쌍(2수) 동시 취소
- 2인용: 마지막 1수 취소

### AI 수 설명·내 수 피드백 (1인용)
- AI 착수 후 잡기·체크·특수 이동·중앙 진출·기물 전개를 구분해 설명
- 사용자가 둔 수에도 중앙 진출·잡기·캐슬링·체크 등의 학습 피드백 제공
- 체크메이트 / 체크 / 특수 이동(캐슬링, 앙파상) / 기물 잡기 / 중앙 점령 구분

### 학습 팁
- 단순한 진행 수가 아니라 현재 보드의 기물 수·중앙 폰·미전개 기물·킹 위치를 확인해 안내

### 기물 설명
- 1인용 모드에서 기물 클릭 시 이동 규칙 한국어 설명 표시

### 기보 (Move History)
- SAN 표기법으로 전체 착수 기록 표시
- 백/흑 2열 그리드 형태

## 반응형 레이아웃

| 화면 크기 | 레이아웃 |
|-----------|---------|
| 모바일 (< 768px) | 세로 단일 컬럼 |
| 태블릿/iPad (≥ 768px) | 보드 + 사이드 패널 2단 |
| 데스크탑 (≥ 1024px) | 보드 + 넓은 사이드 패널 |

- `100dvh` 및 iOS `safe-area-inset` 적용 — 아이폰 노치·하단 홈 표시 영역 회피
- 아이폰 가로 화면에서 체스판을 화면 높이에 맞게 축소
- 2인용 기보는 접기/펼치기 방식으로 체스판과 타이머를 우선 표시

## 2인용 특수 레이아웃

```
┌─────────────────────────────────┐
│  흑 (Black) 카드  [180° 회전]    │  ← 북쪽 플레이어가 읽을 수 있도록
├─────────────────────────────────┤
│                                 │
│          체 스 판                │  ← 고정 방향 (rank 8 위, rank 1 아래)
│   흑 기물(rank 7-8) 위           │
│   백 기물(rank 1-2) 아래         │
│                                 │
├─────────────────────────────────┤
│  백 (White) 카드                 │  ← 남쪽 플레이어가 읽을 수 있도록
├─────────────────────────────────┤
│  [무르기]  [새 게임]              │
└─────────────────────────────────┘
```

- 보드 방향은 차례가 바뀌어도 변경되지 않음 (고정)
- 흑 카드만 `transform: rotate(180deg)` 적용

# 체스 교실 — 기능 설명서

## 개요

**체스 교실**은 React 기반의 설치형 웹 체스 학습 앱입니다. 20단계 기초 학습, 1인용 AI 대전, 2인용 대면 대결을 지원하며 아이폰·아이패드·PC에서 사용할 수 있습니다. 아이폰 홈 화면에 추가할 수 있고, 온라인에서 한 번 준비한 뒤에는 오프라인에서도 다시 실행할 수 있습니다.

- 배포 URL: https://kimgun1981.github.io/chess-learning-app/
- GitHub: https://github.com/kimgun1981/chess-learning-app

---

## 화면 구성

### 1. 메인 메뉴 (ModeSelect)
- 앱 진입 시 가장 먼저 표시
- **기초 학습** / **1인용 (AI 연습)** / **2인용** 모드 선택
- 저장된 대국이 있으면 **지난 게임 이어하기** 표시
- 학습 완료 단계 수와 게임 승패 통계 표시

### 2. 기초 학습 (LessonSelect / LessonPractice)
- 기물 이동, 기물 잡기, 체크 회피, 캐슬링, 프로모션, 체크메이트 등 20단계
- 기물 선택 시 이동 가능한 칸 표시
- 문제에 따라 여러 정답을 인정
- 오답이면 해당 수가 목표와 맞지 않는 이유를 즉시 안내
- 완료한 문제도 다시 풀 수 있으며, 미완료 문제만 모아 복습 가능
- 확인창을 거쳐 전체 학습 진행도 초기화 가능
- 단계별 완료 상태 자동 저장

### 3. 난이도 선택 (DifficultySelect) — 1인용 전용
- 초급 🌱 / 중급 ⚡ / 심화 🔥 3단계

### 4. 시간 선택 (TimeSelect) — 2인용 전용
- 무제한 / 1분 / 3분 / 5분 / 10분 / 30분

### 5. 게임 화면
- 모드에 따라 AI 모드 또는 2인용 모드 UI 표시

## 핵심 기능

### 체스판
- 8×8 그리드, iOS에서도 이모지로 바뀌지 않는 단색 유니코드 기물 렌더링
- **흰 말**: 흰색 실루엣 + 어두운 외곽선
- **검정 말**: 짙은 실루엣 + 밝은 외곽선
- 클릭한 기물의 합법적 이동 칸 하이라이트 (파란 점)
- 체크 상태 킹 칸 빨간 하이라이트
- 힌트 칸 노란 하이라이트
- `grid-rows-8` + `h-full` 로 말 유무와 무관하게 칸 크기 고정

### AI 엔진
| 난이도 | 알고리즘 |
|--------|---------|
| 초급 | 완전 랜덤 |
| 중급 | 그리디 (체크메이트 > 체크 > 기물 잡기 > 중앙 점령 우선) |
| 심화 | 미니맥스 + 알파베타 가지치기, 약 700ms 계산 시간예산 |

계산 시간예산은 한 수를 고르는 데 사용할 최대 계산 시간을 정한 값입니다. 복잡한 보드에서도 화면이 지나치게 오래 멈추지 않도록 제한합니다.

### 타이머 (2인용)
- 선택한 시간을 각 플레이어에게 배분
- 자기 차례일 때만 카운트다운
- 내부 남은 시간을 밀리초 단위로 보관하고 `Date.now()`의 실제 경과 시간을 빼서 계산
- 아이폰·아이패드에서 잠시 다른 화면으로 이동했다 돌아와도 실제 지난 시간 반영
- 30초 이하 + 자기 차례 → 빨간 색 + pulse 애니메이션
- 시간 초과 시 상대방 승리 선언
- 상대에게 체크메이트 가능한 기물이 없으면 시간 초과여도 무승부 처리

### 힌트 (1인용)
- 먼저 모든 합법 수에서 1수 체크메이트가 있는지 확인
- 이후 약 300ms의 계산 시간예산 안에서 기물 점수, 중앙 활용, 폰 전진과 상대 대응을 비교
- 합법 수가 적은 국면은 한 단계 더 깊게 살펴보고, 복잡한 국면은 제한 시간 안의 최선 결과를 사용
- 결과를 절대적인 정답이 아닌 **추천 후보수**로 표시
- 출발 칸·도착 칸을 노란색으로 표시하고 추천 이유 안내

### 무르기 (Undo)
- 1인용: 본인 수 + AI 수 한 쌍(2수) 동시 취소
- 2인용: 마지막 1수 취소

### AI 수 설명·내 수 피드백 (1인용)
- AI 착수 후 잡기·체크·특수 이동·중앙 진출·기물 전개를 구분해 설명
- 사용자가 둔 수에도 중앙 진출·잡기·캐슬링·체크 등의 학습 피드백 제공
- 체크메이트 / 체크 / 특수 이동(캐슬링, 앙파상) / 기물 잡기 / 중앙 점령 구분

### 학습 팁
- 단순한 진행 수가 아니라 현재 보드의 기물 수·중앙 폰·미전개 기물·킹 위치를 확인해 안내

### 기물 설명
- 1인용 모드에서 기물 클릭 시 이동 규칙 한국어 설명 표시

### 기보 (Move History)
- SAN 표기법으로 전체 착수 기록 표시
- 백/흑 2열 그리드 형태
- 현재 대국을 표준 PGN 문자열로 클립보드에 복사
- 날짜가 포함된 `.pgn` 파일로 저장

### 대국 알림과 화면 유지
- 착수·기물 잡기·체크·시간 부족·게임 종료에 서로 다른 효과음 사용
- **소리 켬/끔** 설정을 저장해 다음 접속에도 유지
- 2인용에서는 지원 기기에 착수·체크·시간 경고 진동 제공
- 2인용 대국 중 브라우저가 지원하면 Wake Lock을 요청해 화면이 자동으로 꺼지는 것을 방지
- 진동과 화면 꺼짐 방지는 기기·브라우저·배터리 설정에 따라 사용할 수 없으며, 미지원이어도 대국 기능은 정상 작동

### 통계
- 학습 완료 단계 수를 20단계 기준으로 표시
- 1인용은 나의 승리·AI 승리·무승부를 기록
- 2인용은 백 승리·흑 승리·무승부를 기록
- 같은 종료 결과가 화면 갱신 등으로 중복 기록되지 않도록 게임 식별값을 함께 저장
- 통계는 서버 계정이 아니라 현재 브라우저에만 저장

## 반응형 레이아웃

| 화면 크기 | 레이아웃 |
|-----------|---------|
| 모바일 (< 768px) | 세로 단일 컬럼 |
| 태블릿/iPad (≥ 768px) | 보드 + 사이드 패널 2단 |
| 데스크탑 (≥ 1024px) | 보드 + 넓은 사이드 패널 |

- `100dvh` 및 iOS `safe-area-inset` 적용 — 아이폰 노치·하단 홈 표시 영역 회피
- 상단·하단뿐 아니라 좌우 안전 영역도 반영해 가로 화면의 노치와 둥근 모서리를 회피
- 아이폰 가로 화면에서 체스판을 화면 높이에 맞게 축소
- 2인용 기보는 접기/펼치기 방식으로 체스판과 타이머를 우선 표시

## 홈 화면 설치와 오프라인(PWA)

PWA는 웹페이지를 일반 앱처럼 홈 화면 아이콘으로 실행하게 해 주는 방식입니다.

- `manifest.webmanifest`에서 앱 이름·색상·아이콘·독립 실행 화면 설정
- 프로덕션 빌드에서 서비스 워커를 등록해 HTML, 자바스크립트, 스타일, 아이콘을 현재 기기에 저장
- 온라인일 때는 새 파일을 우선 확인하고, 네트워크 연결에 실패하면 저장된 파일을 사용
- GitHub Pages의 하위 경로에서도 동작하도록 `BASE_URL` 기준으로 서비스 워커 범위 설정
- 오프라인 사용 전 온라인 상태에서 앱을 한 번 정상적으로 열어야 함
- 저장된 학습 기록·대국·통계도 브라우저 내부 저장소를 사용하므로 오프라인에서 유지

## 2인용 특수 레이아웃

```
┌─────────────────────────────────┐
│  흑 (Black) 카드  [180° 회전]    │  ← 북쪽 플레이어가 읽을 수 있도록
├─────────────────────────────────┤
│                                 │
│          체 스 판                │  ← 고정 방향 (rank 8 위, rank 1 아래)
│   흑 기물(rank 7-8) 위           │
│   백 기물(rank 1-2) 아래         │
│                                 │
├─────────────────────────────────┤
│  백 (White) 카드                 │  ← 남쪽 플레이어가 읽을 수 있도록
├─────────────────────────────────┤
│  [무르기] [새 게임] [보드 뒤집기]  │
└─────────────────────────────────┘
```

- 보드 방향은 차례에 따라 자동 변경되지 않으며, **보드 뒤집기** 버튼으로 수동 변경
- 흑 카드만 `transform: rotate(180deg)` 적용

## 로컬 저장

- 진행 중인 대국의 모드·난이도·기보·밀리초 단위 남은 시간·보드 방향 자동 저장
- 저장된 대국이 있을 때 새 게임을 선택하면 기존 저장 게임을 교체할지 먼저 확인
- 마지막 난이도·제한 시간·소리 켬/끔 설정 저장
- 20단계 기초 학습 완료 상태와 게임 승패 통계 저장
- 손상되었거나 지원하지 않는 저장값은 안전한 기본값으로 되돌림
- 모든 정보는 서버가 아닌 현재 브라우저에만 저장

## 자동 테스트

- `npm test`로 Node 내장 테스트 실행
- 설정, AI와 힌트, 20개 학습 문제, 타이머·종료 판정, 로컬 저장, PGN, PWA 설정을 각각 검사
- 특히 모든 학습 문제의 시작 위치와 정답 수가 `chess.js` 규칙에 맞는지 자동 확인
- 배포 전 권장 확인 순서: `npm run lint` → `npm test` → `npm run build`
- `main` 브랜치 push와 Pull Request에서는 GitHub Actions가 테스트·코드 검사·빌드를 자동 실행

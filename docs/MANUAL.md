```
https://kimgun1981.github.io/chess-learning-app/
```

모바일, iPad, PC 모두 지원됩니다.

## 아이폰 홈 화면에 설치하기

아이폰에서는 Safari로 홈 화면에 추가하면 일반 앱처럼 아이콘을 눌러 실행할 수 있습니다.

1. 아이폰의 **Safari**에서 위 주소를 엽니다.
2. 화면 아래 가운데의 **공유** 버튼(위쪽 화살표가 있는 네모)을 누릅니다.
3. 목록을 내려 **홈 화면에 추가**를 누릅니다.
4. 이름이 **체스 교실**인지 확인하고, 오른쪽 위의 **추가**를 누릅니다.
5. 홈 화면에 생긴 **체스 교실** 아이콘을 눌러 실행합니다.

처음 설치할 때와 새 버전을 받을 때는 인터넷 연결이 필요합니다. 인터넷이 연결된 상태에서 앱을 한 번 정상적으로 연 뒤에는 연결이 없어도 홈 화면 아이콘으로 다시 실행할 수 있습니다.

> Chrome이 아니라 Safari에서 열어야 아이폰의 **홈 화면에 추가** 메뉴를 가장 확실하게 사용할 수 있습니다.

## 게임 시작

### 1단계 — 모드 선택

| 버튼 | 설명 |
|------|------|
| 🎓 기초 학습 | 기물 이동부터 체크메이트까지 20단계 실습 |
| 🤖 1인용 (AI 연습) | AI와 1:1 대결. 이유가 표시되는 힌트·수 설명 지원 |
| 👥 2인용 | 같은 기기로 두 명이 대결 |

진행 중인 대국이 있으면 메인 화면에 **지난 게임 이어하기** 버튼이 표시됩니다.
각 모드 카드에는 학습 완료 단계 수 또는 지금까지의 승패 통계가 표시됩니다.

## 게임 조작 방법

### 기물 이동

1. **이동할 기물을 클릭** → 기물이 하이라이트되고 이동 가능한 칸에 파란 점 표시
2. **이동할 목적지 칸을 클릭** → 이동 완료

> 내 차례가 아닌 기물은 선택되지 않습니다.

### 기초 학습

1. 메인 화면에서 **기초 학습**을 누릅니다.
2. 1~20단계 중 연습할 항목을 선택합니다. 이미 끝낸 단계도 다시 선택할 수 있습니다.
3. 안내된 기물과 목적지를 누릅니다.
4. 문제에 따라 정답이 하나 또는 여러 개일 수 있습니다. 인정되는 수를 두면 정답으로 처리됩니다.
5. 오답이면 왜 목표에 맞지 않는지 안내가 표시됩니다. 다른 수를 다시 시도합니다.
6. 정답이면 설명이 나오고 완료 상태가 자동 저장됩니다.
7. 같은 문제를 처음 상태로 풀고 싶으면 **다시 풀기**를 누릅니다.

학습 목록의 추가 기능은 다음과 같습니다.

- **미완료 단계만 복습**: 아직 끝내지 않은 문제만 모아 봅니다.
- **전체 단계 보기**: 완료 여부와 관계없이 20개 문제를 모두 봅니다.
- **학습 기록 초기화**: 확인창을 거친 뒤 모든 완료 표시를 지웁니다. 문제 자체는 삭제되지 않습니다.
- 모든 문제를 완료한 뒤에도 **완료한 단계 다시 보기**로 반복 연습할 수 있습니다.

### 선택 취소

- 다른 빈 칸 또는 이동 불가 칸을 클릭하면 선택이 해제됩니다.

## 화면 구성 (1인용)

```
┌─────────────────────┬──────────────────┐
│                     │  현재 상태 / 팁   │
│                     ├──────────────────┤
│                     │  🤖 AI 수 설명    │
│      체 스 판        ├──────────────────┤
│                     │  기물 설명        │
│                     ├──────────────────┤
│                     │  📋 기보          │
│                     ├──────────────────┤
│                     │ 💡힌트 ↩무르기 🔄 │
└─────────────────────┴──────────────────┘
```

### 사이드 패널 기능

| 항목 | 설명 |
|------|------|
| 현재 상태 / 팁 | 체크 경고 또는 단계별 전략 팁 |
| AI 수 설명 | AI가 방금 둔 수의 잡기·체크·전개 등을 설명 |
| 내 수 피드백 | 내가 둔 수의 학습 포인트를 설명 |
| 기물 설명 | 클릭한 기물의 이동 규칙 |
| 기보 | 백/흑 착수 기록 (SAN 표기) |
| 💡 힌트 | 계산 시간 안에서 찾은 추천 후보수를 노란색으로 표시하고 이유도 안내 (백 차례에만 활성) |
| ↩ 무르기 | 내 수 + AI 수 한 쌍 취소 |
| 🔄 초기화 | 게임을 처음부터 다시 시작 |

힌트는 1수 체크메이트를 먼저 찾고, 그 밖의 수는 약 0.3초 동안 상대 대응까지 비교합니다. 체스에는 상황에 따라 좋은 수가 여러 개 있을 수 있으므로 **정답**이 아니라 **추천 후보수**로 참고하세요.

### 기보 복사와 PGN 저장

1. 한 수 이상 진행하면 기보 아래의 **기보 복사**와 **PGN 저장** 버튼을 사용할 수 있습니다.
2. **기보 복사**를 누르면 다른 메모나 채팅에 붙여넣을 수 있습니다.
3. **PGN 저장**을 누르면 날짜가 포함된 `.pgn` 파일로 내려받습니다.

PGN은 체스 대국 기록을 다른 체스 프로그램에서도 읽을 수 있게 만든 표준 파일 형식입니다.

## 화면 구성 (2인용)

```
┌─────────────────────────────────┐
│   흑 (Black) 카드 [뒤집혀 표시]  │  ← 흑 플레이어가 읽는 방향
├─────────────────────────────────┤
│                                 │
│           체 스 판               │
│                                 │
├─────────────────────────────────┤
│         백 (White) 카드          │
├─────────────────────────────────┤
│       [↩ 무르기]  [🔄 새 게임]   │
└─────────────────────────────────┘
```

### 플레이어 카드

- 자기 차례가 되면 카드 테두리가 초록색으로 강조되고 **● 차례** 표시
- 타이머가 설정된 경우 남은 시간을 표시하며, 내부에서는 밀리초 단위 실제 경과 시간으로 계산
- 30초 이하이고 자기 차례이면 빨간색으로 깜빡임
- 잡은 기물 목록 및 점수 우위 표시

### 소리·진동·화면 꺼짐 방지

- 화면 위의 **소리 켬/끔** 버튼으로 착수·잡기·체크·시간 경고·종료 효과음을 조절합니다.
- 선택한 소리 설정은 현재 브라우저에 저장됩니다.
- 2인용에서는 지원되는 기기에 착수와 경고 진동이 함께 전달됩니다.
- 2인용 대국 화면을 열어 둔 동안, 지원되는 브라우저에는 화면이 자동으로 꺼지지 않도록 요청합니다.
- 아이폰의 무음 설정, 브라우저 권한, 저전력 모드에 따라 소리·진동·화면 유지가 제한될 수 있습니다. 이 경우에도 체스판과 타이머는 정상적으로 작동합니다.

### 2인용 배치 권장

iPad를 테이블 위에 평평하게 놓고 양쪽에 앉습니다.
- 흑 플레이어: 화면 위쪽에 앉음 (흑 카드가 자신 방향으로 읽힘)
- 백 플레이어: 화면 아래쪽에 앉음 (백 카드가 자신 방향으로 읽힘)
- 기본은 rank 8이 위, rank 1이 아래입니다.
- 자리를 바꿔 앉았다면 **보드 뒤집기**로 백·흑 방향을 바꿀 수 있습니다.
- 아이폰에서는 기보가 기본적으로 접혀 있으며 **기보 보기**를 누르면 펼쳐집니다.

2인용에서도 기보 영역 아래의 **기보 복사** 또는 **PGN 저장**으로 대국 기록을 보관할 수 있습니다.

## 학습·게임 통계

- 메인 화면의 **기초 학습** 카드에서 `완료 단계/20`을 확인할 수 있습니다.
- **1인용** 카드에는 AI 대국 수와 나·AI의 승리, 무승부 횟수가 표시됩니다.
- **2인용** 카드에는 2인용 대국 수와 백 승리, 흑 승리, 무승부 횟수가 표시됩니다.
- 게임이 정상적으로 종료되면 통계에 한 번만 반영됩니다.
- 통계는 로그인 계정이 아니라 현재 브라우저에 저장되므로, 브라우저 데이터를 삭제하거나 다른 기기로 바꾸면 이어지지 않습니다.

## 자동 저장과 아이폰 사용

- 한 수 이상 진행한 게임은 자동으로 현재 기기에 저장됩니다.
- 메뉴로 이동해도 **지난 게임 이어하기**로 돌아올 수 있습니다.
- 저장된 게임이 있을 때 새 게임을 시작하면 기존 저장 게임을 새 게임으로 교체할지 확인합니다.
- 초기화나 메뉴 이동처럼 진행 중인 대국에 영향을 주는 동작 전에는 확인창이 표시됩니다.
- 아이폰의 Safari에서 세로·가로 화면을 모두 사용할 수 있으며, 노치·둥근 모서리·하단 홈 표시 영역을 피해 화면이 배치됩니다.
- 2인용 타이머는 밀리초 단위 기준 시각을 사용하므로 앱이 잠시 백그라운드로 가도 실제 경과 시간을 반영합니다.
- 홈 화면 앱과 Safari는 같은 웹앱이라도 저장 공간이 다르게 보일 수 있습니다. 이어하기가 보이지 않으면 처음 사용한 방식으로 다시 실행하세요.

### 오프라인에서 사용할 때

1. 인터넷에 연결된 상태에서 최신 체스 교실을 한 번 엽니다.
2. 화면이 정상적으로 나타난 뒤 홈 화면 아이콘으로 다시 실행해 봅니다.
3. 이후 연결이 끊겨도 캐시에 준비된 앱을 열고 학습·대국을 이용할 수 있습니다.

새 버전 업데이트는 인터넷 연결 중에 받습니다. 오프라인에서 처음 접속하거나 브라우저 저장 공간을 지운 직후에는 앱 파일이 준비되지 않아 열리지 않을 수 있습니다.

## 개발 / 운영 가이드

### 로컬 실행

```bash
# 저장소 클론
git clone https://github.com/kimgun1981/chess-learning-app.git
cd chess-learning-app

# 의존성 설치
npm install

# 개발 서버 실행 (http://localhost:5173)
npm run dev
```

### 빌드

```bash
npm test
npm run lint
npm run build
# dist/ 폴더에 빌드 결과물 생성
```

`npm test`는 AI·힌트·20단계 문제·시계·저장·PGN을 자동으로 확인합니다. GitHub의 `main` 브랜치에 코드를 올리거나 Pull Request를 만들 때도 GitHub Actions가 `npm test`, `npm run lint`, `npm run build`를 자동 실행합니다.

### 배포 (GitHub Pages)

```bash
npm run deploy
# 자동으로: vite build → dist 결과를 gh-pages 브랜치에 게시
```

`npm run deploy`는 공개 페이지를 갱신하는 명령입니다. `main` 브랜치의 소스 코드 커밋·푸시는 별도로 관리합니다.

## 문제 해결

| 증상 | 해결 방법 |
|------|---------|
| 화면이 이전 버전으로 보임 | 인터넷 연결 후 앱을 완전히 닫았다 다시 엽니다. PC에서는 Cmd+Shift+R (Mac) / Ctrl+Shift+R (Win)으로 강력 새로고침 |
| AI가 응답하지 않음 | 심화 난이도는 계산에 1~2초 소요됨. 정상 동작입니다 |
| 기물이 이동되지 않음 | 내 차례인지 확인. 상대 기물은 선택 불가 |
| 시간이 줄어들지 않음 | 무제한 모드로 설정된 상태입니다 |
| 홈 화면에 추가가 보이지 않음 | 아이폰의 Safari에서 주소를 다시 열고 공유 버튼을 누릅니다 |
| 오프라인에서 열리지 않음 | 인터넷 연결 후 페이지를 한 번 끝까지 연 다음 다시 시도합니다 |
| 소리나 진동이 나지 않음 | 화면의 소리 설정과 아이폰 무음·저전력 설정을 확인합니다. 일부 브라우저는 진동을 지원하지 않습니다 |
| 화면이 자동으로 꺼짐 | 기기 또는 브라우저가 화면 꺼짐 방지를 지원하지 않을 수 있습니다. 아이폰의 자동 잠금 시간을 임시로 늘립니다 |
